# ADR 0015 — remotesapi access is controlled by an address allowlist, not by a credential

- **Status:** superseded by ADR 0016 (the endpoint this ADR governed has been replaced; kept as the record of why)
- **Date:** 2026-08-02
- **Bead:** `shotwright-2sr.3`
- **Phase the decision landed in:** I
- **Amends:** ADR 0013 (the remotesapi exposure consequence only)

## Context

A remote backup endpoint adopted under ADR 0013 was found to be inadequately
protected. It was replaced rather than hardened, and the replacement is the
subject of ADR 0016. The details of the replaced endpoint are deliberately not
kept here.

## Decision

Superseded. See ADR 0016.
