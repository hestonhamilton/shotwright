# Layer A of the tarball leak gate: the allowlist of what may ship.
#
# Every path inside the packed tarball's package/ directory must match one entry
# here or the gate fails. This layer is content-blind on purpose — it catches a
# newly-shipped file regardless of what is in it, which is the failure mode
# `files` in package.json cannot cover on its own.
#
# README.md and package.json are listed because npm ships them UNCONDITIONALLY,
# regardless of `files` (npm/cli wiki, Files & Ignores, rule 5). Omitting them
# here would fail the gate on a correct tarball.
#
# Syntax, deliberately minimal — no glob engine, no surprises:
#   path/**   matches anything under path/
#   path      matches exactly that path
#   # ...     comment
#
# Adding a line here widens what may ship. Treat a diff to this file as the
# security-relevant part of a release PR.
#
# EVERY FILE IS LISTED EXACTLY. Until 2026-10-05 this read `dist/**` and
# `templates/**`, and both E9.V redteams showed the same thing: a 45th file under
# either prefix — a stray compiler artifact, an unexpected template, a nested
# archive — passed Layer A while this header claimed it would be caught. A
# prefix allowlist is a directory boundary, not a manifest. The cost of the
# exact list is that adding a source module means adding its dist/ entries
# here; that edit is the reviewed change the design wants, not overhead.
#
# LICENSE is listed for the same reason as README.md: npm ships it
# UNCONDITIONALLY when present, regardless of `files`. It arrived with the
# AGPL-3.0-or-later relicense (ADR 0018, shotwright-746.18.8) and this line is
# the deliberate widening that admitted it — the gate correctly failed on the
# new file until it was added here, which is the layer working, not breaking.
#
# NOTICE carries the copyright notice that used to sit above the license text.
# It moved out of LICENSE on 2026-10-07 (shotwright-746.18.36) because GitHub's
# detector classified the preamble-plus-text file as "Other". npm does NOT ship
# NOTICE unconditionally (measured with `npm pack --dry-run`), so it is listed
# in package.json `files` and admitted here.
